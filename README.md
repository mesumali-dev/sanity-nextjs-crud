# 📝 Sanity.io Headless CMS & Next.js CRUD Application

[![Next.js](https://img.shields.io/badge/Next.js-14-black?style=flat-square&logo=next.js)](https://nextjs.org/)
[![Sanity](https://img.shields.io/badge/Sanity-v3-red?style=flat-square&logo=sanity)](https://www.sanity.io/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue?style=flat-square&logo=typescript)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/TailwindCSS-38bdf8?style=flat-square&logo=tailwind-css)](https://tailwindcss.com/)

> Full-stack content management system demonstrating real-time CRUD (Create, Read, Update, Delete) operations by coupling Next.js with Sanity Headless CMS and GROQ querying.

---

## 🌟 Features

- **Complete CRUD Operations:** Create, retrieve, modify, and delete content entries dynamically.
- **Sanity Studio Integration:** Embedded Sanity Studio for structured editorial workflow.
- **GROQ Queries:** Fast and expressive content fetching using Sanity's Graph-Relational Object Queries.
- **Optimized Media Delivery:** Automatic CDN asset optimization, responsive images, and blur placeholders.
- **Type-Safe Schemas:** Fully typed content document schemas.

---

## 🛠️ Architecture

- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS
- **CMS Backend:** Sanity.io Studio v3
- **Query Language:** GROQ (Graph-Relational Object Queries)

---

## 🚀 Installation & Setup

```bash
# Clone repo
git clone https://github.com/mesumali-dev/sanity-nextjs-crud.git
cd sanity-nextjs-crud

# Install dependencies
npm install

# Set up environment variables (.env.local)
# NEXT_PUBLIC_SANITY_PROJECT_ID=your_project_id
# NEXT_PUBLIC_SANITY_DATASET=production

# Run development server
npm run dev
```
